# 切线算法错误码排查手册

接口实际返回四位数字错误码。数字码是调用方用于分流、告警和统计的唯一错误码；英文标识仅用于兼容既有调用方和辅助排查。

## 读取规则

| 响应位置 | 数字错误码字段 | 英文兼容字段 | 说明 |
| --- | --- | --- | --- |
| HTTP 422 `detail` | `detail.code` | `detail.legacy_code` | 请求整体失败原因 |
| HTTP 422 `detail.issues[]` | `error_code` | `code` | 单条输入数据问题，必须逐条处理 |
| HTTP 200 `errors[]` | `error_code` | `reason` | 可隔离的局部计算或数据问题，其他结果仍有效 |
| HTTP 200 `errors[]` 且 `stage=mixing_trace` | `error_code` | `reason` | 单机台混料追溯问题 |

`message` 为包含算法范围、数据对象和字段定位的中文说明，例如 `切线-订单 ORD-001中‘订单名称’字段不符合编码规则`、`排产/定线-MAIN-001：同一物理 main 内存在重复的 Buffer 编码`、`混料-EA004：机台和源产品的工艺时长缺失`。它仅供人工阅读；`dataset`、`field`、`record_key` 和 `warning_key` 不是错误码。不要依据 `message` 做程序分支。

| 范围 | 分类 |
| --- | --- |
| `1001-1099` | HTTP 接口与请求错误 |
| `2101-2199` | 订单数据校验错误 |
| `2201-2299` | 机台数据校验错误 |
| `2301-2399` | AGV 机台绑定数据校验错误 |
| `2401-2499` | Buffer 数据校验错误 |
| `2501-2599` | 产品数据校验错误 |
| `2601-2699` | 工艺路线数据校验错误 |
| `2701-2799` | 车间数据校验错误 |
| `2801-2899` | 产线数据校验错误 |
| `2901-2999` | Pending、活动事件、持久化状态、快照和请求数据校验错误 |
| `3001-3099` | 算法计算与状态错误 |
| `3101-3199` | 混料追溯错误 |
| `4001-4099` | 业务状态，不是系统故障 |
| `9001-9099` | 未统一捕获的内部异常 |

## 1xxx 接口与请求错误

| 错误码 | `legacy_code` | 错误原因 | 排查位置 |
| --- | --- | --- | --- |
| `1001` | `STATIC_DATA_INVALID` | V6 静态目录缺少数据集、记录格式错误、主键缺失/重复或 Schema 校验失败 | `app/api/v6_api.py`、`app/service/catalog_store.py` |
| `1002` | `IDEMPOTENCY_KEY_REUSED` | 同一 `Idempotency-Key` 提交了不同版本或内容 | 静态目录发布/补丁请求头和内容哈希 |
| `1003` | `CATALOG_VERSION_CONFLICT` | 已有目录版本对应不同内容 | `catalog_version` 与已发布内容 |
| `1004` | `BASE_CATALOG_VERSION_NOT_FOUND` | 增量更新的基准目录版本未保留 | 使用保留的基准版本重建补丁 |
| `1005` | `BASE_CATALOG_VERSION_STALE` | 增量更新基准版本不是当前版本 | 拉取当前目录后重新提交 |
| `1006` | `STATIC_CATALOG_REQUIRED` | V6 动态评估前尚未发布静态目录 | 先发布完整静态目录 |
| `1007` | `CATALOG_VERSION_NOT_FOUND` | 请求的静态目录版本未保留 | 使用保留版本或重新发布 |
| `1008` | `STATIC_CATALOG_DATA_MISSING` | 动态快照引用的机台或 Buffer 不在静态目录中 | 查看 `missing_references` |
| `1009` | `DYNAMIC_DATA_INVALID` | V6 动态请求缺字段、类型错误或包含未声明字段 | `app/schemas/v6_schema.py` 和响应 `message` |
| `1010` | `BACKEND_DATA_INVALID` | 标准切线接口的后端数据不完整、格式错误或关联关系错误 | 继续处理 `detail.issues[]` 的 `error_code` |
| `1011` | `SNAPSHOT_CONVERSION_FAILED` | 基础校验通过，但无法转换为算法快照 | `app/adapters/snapshot_adapter.py` 和响应 `message` |
| `1012` | `REQUEST_VALIDATION_ERROR` | 请求在普通接口加载阶段格式错误或原始字段标准化失败 | 继续处理 `detail.issues[]` 的 `error_code` |

`1010` 和 `1012` 只说明请求整体失败，不能替代明细码。一个请求可同时返回订单、机台和 Buffer 的多个问题。

## 2xxx 输入数据校验错误

### 2.1 数据域和码段

| 码段 | `dataset` | 说明 |
| --- | --- | --- |
| `21xx` | `orders` | 订单、订单产品和订单车间关系 |
| `22xx` | `machine_realtime`、`machine_master`、`machine_process_times`、`machine_lines` | 机台实时、主数据、工艺时长和产线关系 |
| `23xx` | `agv_relations` | AGV 当前绑定和历史绑定 |
| `24xx` | `buffer_realtime`、`buffer_master` | Buffer 实时库存、主数据、容量和服务工序 |
| `25xx` | `products` | 产品主数据 |
| `26xx` | `process_routes` | 工艺路线、顺序和上下游关系 |
| `27xx` | `workshops` | 车间主数据 |
| `28xx` | `lines` | 产线主数据 |
| `2901-2919` | `pending_cutline_plans` | Pending 计划、候选机台和基线绑定 |
| `2921-2939` | `active_cutline_events` | 已激活切线事件 |
| `2941-2959` | `return_suggested_event_ids`、`mixed_cutline_event_ids` | 持久化事件 ID |
| `2961-2979` | `snapshot_meta` | 快照元数据 |
| `2981-2999` | 根请求或未映射数据集 | 请求结构 |

同一原因在不同数据域使用不同数字码。例如 `missing_reference`：订单为 `2108`，机台为 `2208`，AGV 为 `2308`，Buffer 为 `2408`，产品为 `2508`，工艺路线为 `2608`。

### 2.2 通用原因后缀

下表的后缀适用于 `21xx-28xx` 数据域。例如订单产品引用缺失为 `21` + `08` = `2108`，机台主数据重复为 `22` + `05` = `2205`。

| 后缀 | 原始 `code` | 完整码示例 | 错误原因与排查位置 |
| --- | --- | --- | --- |
| `01` | `empty_dataset` | `2101` | 必需数据集为空；检查上游查询条件、权限和快照时间 |
| `02` | `empty_code` | `2202` | 编码字段为空或全为空白；按 `record_key`、`field` 回查记录 |
| `03` | `empty_value` | `2403` | 必填业务值为空；检查字段值和转换逻辑 |
| `04` | `null_field` | `2704` | 当前场景不允许字段为 `null`；按 `field` 补齐数据 |
| `05` | `duplicate_key` | `2105` | 主键或业务键重复；合并、删除或修正重复记录 |
| `06` | `invalid_value` | `2406` | 数值不在业务范围；例如 `buffer_master.max_capacity` 必须大于零 |
| `07` | `invalid_reference` | `2407` | 关联字段与目标记录不一致；检查两端编码和名称 |
| `08` | `missing_reference` | `2108` | 被引用记录不存在；先按 `field` 找引用端，再补齐目标数据 |
| `09` | `ambiguous_reference` | `2309` | 引用匹配多条记录；消除重复主数据或同名运行订单 |
| `10` | `name_mismatch` | `2110` | 编码与名称不匹配 |
| `11` | `workshop_mismatch` | `2111` | 关联记录属于不同车间；核对订单、Buffer、机台和路线车间 |
| `12` | `binding_conflict` | `2312` | 同一机台或绑定在同一时刻冲突；检查 AGV 生效时间和机台编码 |
| `13` | `missing_agv_binding` | `2213` | 运行机台没有有效 AGV 绑定；核对实时机台、`equipmentid`、`createtime` |
| `14` | `unknown_process_name` | `2614` | 工序名称无法映射到内部目录；检查名称、空白和大小写 |
| `15` | `duplicate_sequence` | `2615` | 同一车间工序序号重复 |
| `16` | `broken_process_route` | `2616` | 上下游编码或名称与排序后的相邻工序不一致 |
| `17` | `invalid_last_process_downstream` | `2617` | 最后一道工序仍填写下游工序 |
| `18` | `missing_silk_screen_process` | `2618` | 车间路线缺少丝网工序 |
| `19` | `duplicate_silk_screen_process` | `2619` | 同一车间出现多个丝网工序 |
| `20` | `silk_screen_not_last` | `2620` | 丝网不是车间最后一道工序 |
| `21` | `load_error` | `2321` | 原始后端载荷标准化失败；常见于 AGV 原始字段和标准字段冲突 |
| `91` | `extra_forbidden` | `2291` | 请求发送未声明字段；删除字段或升级双方契约 |
| `92` | `missing` | `2592` | Schema 必填字段缺失；补齐字段 |
| `93` | `float_parsing` | `2193` | 数字字段无法解析；传递 JSON 数字或可解析数字字符串 |
| `94` | `model_type` | `2294` | 机台根节点或嵌套对象类型错误；检查 JSON 结构 |
| `99` | 其他 Schema/校验原因 | `2199` | 未被单独编号的校验原因；保留 `code`、`field` 和 `message` 后升级排查 |

`29xx` 需要在同一百位内继续区分数据集，因此 Schema 错误使用较短后缀：`15=extra_forbidden`、`16=missing`、`17=float_parsing`、`18=model_type`、`19=其他`。例如根请求类型错误为 `2998`，快照元数据缺失为 `2976`。

### 2.3 高频示例

订单产品不存在：

```json
{
  "detail": {
    "code": "1010",
    "legacy_code": "BACKEND_DATA_INVALID",
    "issues": [
      {
        "error_code": "2108",
        "code": "missing_reference",
        "dataset": "orders",
        "field": "product_code",
        "record_key": "ORD-001"
      }
    ]
  }
}
```

处理：先确认 `ORD-001.product_code`，再确认 `products` 中存在且唯一的同编码产品。不要只修改 `product_name`。

机台实时数据带了已废弃字段：

```json
{
  "detail": {
    "code": "1010",
    "legacy_code": "BACKEND_DATA_INVALID",
    "issues": [
      {
        "error_code": "2291",
        "code": "extra_forbidden",
        "dataset": "machine_realtime",
        "field": "completed_quantity",
        "record_key": "index:0"
      }
    ]
  }
}
```

处理：删除 `completed_quantity` 或停止上游发送该字段。机台实时数据只应发送当前 Schema 定义的字段。

## 3xxx 算法计算与状态错误

这些错误位于 HTTP 200 的 `errors[]`。`stage`、`warning_key` 与错误码共同构成定位键。

### 3.1 主 Buffer 聚合

| 错误码 | `reason` | 错误原因 | 首要排查项 |
| --- | --- | --- | --- |
| `3001` | `main_id_unavailable` | Buffer 实时记录的物理 `main_id` 为空 | `buffer_realtime.main_id` |
| `3002` | `inventory_unavailable` | Buffer 库存不是有限非负数 | `current_quantity` |
| `3003` | `duplicate_buffer_id` | 同一物理 main 内 `buffer_code` 重复 | 同一 `main_id` 下的实时 Buffer |
| `3004` | `static_buffer_mapping_unresolved` | Buffer Master 或工艺关系无法唯一匹配 | `buffer_master`、Buffer 工艺关系 |
| `3005` | `workshop_conflict` | 同一物理 main 的 Buffer 或订单车间不一致 | Buffer、订单、路线的车间编码 |
| `3006` | `service_process_conflict` | 同一物理 main 的服务工序区间不一致 | Buffer 服务工序 |
| `3007` | `capacity_unavailable` | 至少一个 Buffer 没有有效正容量 | `max_capacity` |
| `3008` | `inventory_at_or_above_capacity` | 物理库存达到或超过总容量 | 库存和总容量 |
| `3009` | `buffer_code_index_conflict` | 一个 `buffer_code` 映射到多个物理 main | Buffer 归属关系 |
| `3010` | `order_mapping_not_found` | Buffer 绑定产品没有当前运行订单 | `bound_source_name` 和订单状态 |
| `3011` | `order_mapping_ambiguous` | Buffer 绑定产品匹配多个当前运行订单 | 同产品的运行订单 |

### 3.2 其他管道错误

| 错误码 | `stage` / `reason` | 错误原因 |
| --- | --- | --- |
| `3020` | `pending_cutline_confirmation` / `pending_cutline_detection_error` | Pending 基线、AGV 历史或候选上下文无法无歧义比较 |
| `3021` | `active_event_creation` / `pending_plan_not_found` | 确认结果引用的 Pending 计划不在请求状态内 |
| `3022` | `active_event_creation` / `active_event_creation_error` | 已确认切线无法生成合法 Active 事件 |
| `3023` | `active_event_merge` / `active_event_identity_conflict` | 新事件与已有事件业务身份冲突 |
| `3024` | `return_evaluation` / `target_interval_not_found` | Active 事件找不到唯一目标净速率区间 |
| `3025` | `return_evaluation` / `target_interval_ambiguous` | Active 事件匹配多个目标净速率区间 |
| `3026` | `silk_screen_transition` / `silk_screen_transition_calculation_error` | 丝网完工或清台准备数据无法计算 |
| `3027` | `stockout_candidate`、`overflow_candidate` / `candidate_machine_calculation_error` | 候选机台的 AGV、订单、产品或产能数据无法计算 |
| `3028` | `stockout_selection`、`overflow_selection` / `machine_selection_evaluation_error` | 候选筛选或切线影响模拟失败 |
| `3029` | `stockout_plan`、`overflow_plan`、`pending_cutline_creation` / `value_error` | 方案构造或 Pending 状态投影失败 |
| `3099` | 其他管道错误 | 未单独编号的局部算法错误；保留 `stage`、`reason` 和完整 `message` 后升级排查 |

## 31xx 混料追溯错误

混料失败以 `errors[]` 的 `stage="mixing_trace"` 返回，必须结合 `machine_code` 定位。

| 错误码 | `reason` | 错误原因 |
| --- | --- | --- |
| `3101` | `selected_machine_context_incomplete` | 方案或事件缺少机台、订单、工序、切线时间等上下文 |
| `3102` | `same_order_transition_invalid` | 源订单和目标订单相同 |
| `3103` | `source_order_not_found` | 源订单不存在或不唯一 |
| `3104` | `target_order_not_found` | 目标订单不存在或不唯一 |
| `3105` | `cutline_plan_product_mismatch` | 方案产品编码和订单产品编码不一致 |
| `3106` | `same_product_transition_no_mixing` | 源、目标产品相同，不产生混料 |
| `3107` | `machine_runtime_not_found` | 机台实时记录缺失 |
| `3108` | `machine_runtime_ambiguous` | 同一机台存在多条实时记录 |
| `3109` | `runtime_quantity_invalid` | 30 分钟输入/产出量不是有限非负数 |
| `3110` | `runtime_actual_capacity_unavailable` | 根据实时量计算出的实际产能不为正 |
| `3111` | `process_duration_not_found` | 机台和源产品的工艺时长缺失 |
| `3112` | `process_duration_ambiguous` | 机台和源产品的工艺时长重复 |
| `3113` | `process_duration_invalid` | `proc_seconds` 不是有限非负数 |
| `3114` | `mix_start_time_unrepresentable` | 混料开始时间计算溢出或类型错误 |
| `3199` | 其他混料错误 | 未单独编号的混料追溯错误 |

## 4xxx 业务状态

业务状态不是接口错误，当前继续通过业务结果中的 `reason` 返回，不附加数字错误码。`no_candidate_machine`、`insufficient_capacity`、`not_yet_time_to_prepare`、`all_return_conditions_met` 均应由业务流程处理，不应按 4xx/5xx 故障重试。

## 500 和 9xxx

未捕获异常仍返回 HTTP 500，当前不向接口暴露内部数字码。`9001-9099` 保留给日志和运维归档使用。排查时保存完整请求、接口路径、`run_id`、`snapshot_meta.snapshot_time`，并查看容器内 `/app/logs/algorithm-exceptions.log` 或宿主机 `deploy/logs/algorithm-exceptions.log` 的完整 traceback。
