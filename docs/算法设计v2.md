# 算法设计 v2 — 切线预警与混料追溯系统

## 一、算法总览

系统需要两类核心算法，外加一个支撑两者的基础计算层：

```
┌─────────────────────────────────────────────────┐
│              基础层：产能计算                      │
│  机台有效产能 / Buffer 净消耗速率 / 订单剩余量      │
└──────────────┬──────────────────────────────────┘
               │
       ┌───────┴────────┐
       ▼                ▼
┌─────────────┐   ┌──────────────────┐
│ 算法A        │   │ 算法B             │
│ 切线时机预测  │   │ 混料追溯          │
│ + 方案推荐   │   │ + MES 接口推送    │
└─────────────┘   └──────────────────┘
```

## 二、基础层：产能计算

所有上层算法的输入依赖此层。

### 2.1 机台有效产能

机台有三种状态，有效产能直接由当前实时状态决定，不做统计估算：

```
机台状态 = 运行  → 有效产能 = 静态表7[机台ID, 当前型号].实际产能(片/h)
机台状态 = 待机  → 有效产能 = 0
机台状态 = 停机  → 有效产能 = 0，同时触发异常标记
```

待机涵盖保养中、换液中等所有非生产状态。

- 机台状态来源：机台实时状态接口 → `status` 字段
- 实际产能来源：静态表7（按机台ID + 当前型号查询）

**例**：硼扩机台 pk01，当前状态=运行，生产型号 HG182T，静态表7 中该机台该型号实际产能=9600 片/h
```
有效产能 = 9600 片/h
```
同一机台 pk02，当前状态=待机（保养中）：
```
有效产能 = 0  → 不纳入产能计算
```

### 2.2 Buffer 段内区间库存与净消耗速率

**物理结构**：每个 Buffer 段共用一个物理 Buffer 池，物料流向严格按工序顺序流动，不能跳工序。

```
制绒(型号A) → [Buffer池] → 硼扩(型号A) → [Buffer池] → 氧化(型号A) → [Buffer池] → 碱抛(型号A)
```

Buffer 池里的物料按"来源工序"可以区分出各工序阶段的在途量：

```
Buffer段1 库存分解（型号X）：
  区间库存[制绒→硼扩] = Buffer池中 来源工序=制绒、型号=X 的物料量
  区间库存[硼扩→氧化] = Buffer池中 来源工序=硼扩、型号=X 的物料量
  区间库存[氧化→碱抛] = Buffer池中 来源工序=氧化、型号=X 的物料量
```

数据来源：动态表2 新增字段"来源工序编号"（甲方可提供）。

**区间净消耗速率**：对 Buffer 段内每对相邻工序 (工序i → 工序i+1)，针对型号 X，**仅统计当前状态=运行的机台**：

```
区间净消耗速率[工序i→工序i+1, 型号X](片/h)
  = 生产型号X且状态=运行的工序i+1机台吞入速率之和
  - 生产型号X且状态=运行的工序i机台产出速率之和
```

- 净消耗速率 > 0：该区间物料在消耗，趋向断料
- 净消耗速率 < 0：该区间物料在积累，趋向溢满
- 数据来源：动态表1（机台实时状态，含当前生产型号）+ 静态表7（实际产能）

**各 Buffer 段工序结构与最大容量**

| Buffer 段 | 段内工序顺序 | 段总容量（片） | 备注 |
|---|---|---|---|
| 制绒→碱抛上 | 制绒→硼扩→氧化→碱抛 | **156000** | 3个区间 |
| 碱抛下→RCA上 | 碱抛→Poly→退火→RCA | **160800** | 3个区间 |
| RCA下→ALD上 | RCA→ALD | **20400** | 1个区间，容量极小 ⚠️ |
| ALD下→丝网上 | ALD→正膜→背膜→丝网 | **278400** | 3个区间 |

段总容量是所有型号、所有区间共用的物理上限。

### 2.3 区间耗尽 / 溢满预测时间

监控颗粒度：**Buffer 段 × 相邻工序区间 × 型号**，三者组合。

```
区间耗尽预测时间[工序i→工序i+1, 型号X]
  = 区间库存[工序i→工序i+1, 型号X] / 区间净消耗速率[工序i→工序i+1, 型号X]
  （净消耗速率 > 0 时有效）

溢满预测时间[Buffer段S, 型号X]
  = (段总容量[S] - Σ 各型号各区间库存之和) / |区间净消耗速率[工序i→工序i+1, 型号X]|
  （净消耗速率 < 0 时有效；溢满是段级别的，因为 Buffer 池物理共用）
```

**例**：
```
区间库存[制绒→硼扩, HG182T] = 1600 片
区间净消耗速率 = +3200 片/h

耗尽预测时间 = 1600 / 3200 = 0.5h = 30min → 触发断料预警 ✓
```

## 三、算法 A：切线时机预测与方案推荐

### 3.1 触发条件判断

**预警颗粒度：Buffer 段 × 相邻工序区间 × 型号。**

每个调度周期，基于**当前运行机台的静态快照**，对所有 Buffer 段内所有区间的所有在产型号执行：

```
FOR 每个 Buffer 段 S:
  FOR 每对相邻工序 (工序i → 工序i+1) in S:
    FOR 每个在产型号 X:

      IF 区间耗尽预测时间[工序i→工序i+1, X] <= cutline_lead_minutes[S]:
          → 触发"断料预警"，进入切线方案推荐（3.2 节）

      IF 溢满预测时间[S, X] <= cutline_lead_minutes[S] AND 区间净消耗速率 < 0:
          → 触发"溢满预警"，进入切线方案推荐（3.2 节）
```

同一 Buffer 段内可能同时有多个区间触发预警，按**耗尽预测时间最短**的区间优先处理。

**例**：Buffer 段 1 同时出现两个预警
```
区间[制绒→硼扩, HG182T]：耗尽预测时间 = 30min  ← 优先处理
区间[硼扩→氧化, HG210R]：耗尽预测时间 = 45min
```

### 3.2 候选机台筛选

本节只做**静态资格过滤**，产出候选池。影响校验在 3.3 节逐台选取时执行。

**候选机台唯一条件**：同时满足以下两点

```
条件1：机台所属工序 = 预警区间的工序i（产出侧）
条件2：机台当前生产型号的硅片尺寸 = 预警型号X 的硅片尺寸
       AND 机台当前生产型号的形状代码 = 预警型号X 的形状代码
       （形状代码：R 或 N）
条件3：机台当前状态 = 运行
条件4：机台车间相同
```

> **S2 车间特例**：形状代码 R 和 P 的产品，在丝网工序之前共用机台，判断候选时视为同形状代码。

不满足上述条件的机台**不纳入候选**，不设兜底选项（如跨尺寸或跨形状代码），由人工介入处理。

**溢满预警候选池（切走方向）**

```
条件1：机台所属工序 = 预警区间的工序i（产出侧）
条件2：机台当前生产型号 = 预警型号X
条件3：机台当前状态 = 运行
条件4：存在至少一个合适的目标型号Y：
         同硅片尺寸 AND 同形状代码
         目标区间[工序i→工序i+1, Y]当前存在产能缺口（切过去有意义）
条件5：机台车间相同（确认）
```

> 若溢满候选池为空，输出"无处可切"，人工介入。

### 3.3 切入量 / 切走量计算

本节从候选池中**逐台选取**，每选一台执行一次影响校验。

**断料预警：逐台选取**

候选池按空闲度从高到低排序。

```
产能缺口(片/h) = 工序i+1 吞入型号X 的速率 - 工序i 当前产出型号X 的速率

WHILE 产能缺口 > 0 AND 候选池非空:
    取空闲度最高的机台 M

    执行借出影响校验：
      模拟借出 M 后，重新计算原区间[工序i→工序i+1, 原型号]的耗尽预测时间
      IF 耗尽预测时间 <= cutline_lead_minutes → 跳过 M，取下一台（借出会导致原产线断料）
      IF 耗尽预测时间 > cutline_lead_minutes → 选中 M，加入借用列表
        产能缺口 -= 静态表7[M, 预警型号X].实际产能

IF 产能缺口 > 0（候选池耗尽仍未补足）→ 输出预警，人工介入，并附出以下信息：
  - 当前各候选工序机台列表（编号、型号、尺寸、形状代码、产能、状态）
  - 所需补充产能
```

**例**：区间[制绒→硼扩, HG182T] 断料预警，产能缺口 3200 片/h

候选池（同尺寸182、同形状代码R、状态=运行的制绒机台）：

| 机台 | 当前型号 | 实际产出 | UPH | 空闲度 | 切换后可贡献产能 |
|---|---|---|---|---|---|
| zr03 | HG182R | 8000 片/h | 10000 片/h | 20% | 8000 片/h |

```
取 zr03：
  借出影响校验：
    借出后 HG182R 制绒产能 = 0
    区间耗尽预测时间[制绒→硼扩, HG182R] = 20000 / 9600 = 125min > 30min → 通过
  选中 zr03，产能缺口 = 3200 - 8000 = -4800（已补足）

切线方案：zr03 立即切线
```

**溢满预警：逐台选取**

```
产能过剩量(片/h) = 工序i 当前产出型号X 的速率 - 工序i+1 吞入型号X 的速率

按产能利用率从高到低排序候选池：

WHILE 溢满风险未消解 AND 候选池非空:
    取产能利用率最高的机台 M
    对目标型号Y执行影响校验：
      模拟 M 切入后，重新计算目标区间[工序i→工序i+1, Y]的溢满预测时间
      IF 溢满预测时间 <= cutline_lead_minutes → 换下一个Y；若所有Y均不通过 → 跳过 M
    选中 M（切走到型号Y），加入切走列表
    重新计算原区间净消耗速率
    IF 溢满风险消解 → 停止迭代

IF 溢满风险未消解（候选池耗尽）→ 输出预警，人工介入
```

### 3.4 切回时机判断

切线后，被借入机台开始生产预警型号X，净消耗速率从正转负。满足以下三条件时触发切回建议：

```
切回触发条件（三条全部满足，AND）：

条件1：区间净消耗速率[工序i→工序i+1, 型号X] < 0
       （产能过剩，库存在积累）

条件2：条件1连续成立的持续时间 > stability_window_minutes
       系统维护 negative_start_time 字段：
         净消耗速率首次 < 0 时记录 negative_start_time
         净消耗速率恢复 >= 0 时清零
         持续时间 = 当前时间 - negative_start_time

条件3：区间库存[工序i→工序i+1, 型号X] > 安全库存水位
       安全库存水位 = cutline_lead_minutes × |当前净消耗速率|
       （切回后万一再次失衡，库存至少还能支撑一个完整预警响应时间）
```

**例**：zr03 切线后，持续监测区间[制绒→硼扩, HG182T]

```
切线后净消耗速率 = 19200(硼扩吞入) - 24000(制绒产出) = -4800 片/h

持续监测到 T+20min（= stability_window）：
  条件1：-4800 < 0 ✓
  条件2：持续 20min ✓
  条件3：区间库存 = 1600 + 4800×(20/60) = 3200 片
         安全库存水位 = 30min/60 × 4800 = 2400 片
         3200 > 2400 ✓

→ 触发切回建议：zr03 切回生产原型号
```

### 3.5 丝网工序特殊处理

丝网是 Buffer 段 4 的出口工序，切线必须停机清台。丝网切线有两种触发情况：

**情况 1：不同产品型号之间的切线（由 Buffer 水位触发）**

```
触发逻辑与其他工序相同（3.1 节），但推荐方案中额外标注：
  - 需停机清台
  - 预计停机时长 = silk_screen_clear_minutes
  - 切线准备时刻 = 预警时刻（操作员需立即开始准备清台）
```

**情况 2：同型号切换订单（由订单进度触发）**

```
当前订单剩余量 = 订单总量 - 已完成数量
预计完工时刻   = 当前时间 + 当前订单剩余量 / 丝网机台当前产能
切线准备时刻   = 预计完工时刻 - silk_screen_clear_minutes

→ 在切线准备时刻触发预警，提示操作员准备清台
→ 清台完成后切换到下一订单型号
→ 不依赖 Buffer 水位
```

## 四、算法 B：混料追溯

### 4.0 物理模型说明

机台分为三个区域：**上料区 → 工艺区 → 下料区**。AGV 以批次方式搬运物料，每次最多 10 个花篮，每篮 120 片（单批最多 1200 片）。工艺区通过机械臂按 **FIFO** 方式逐个花篮送入传送带，**串行**执行。

切线时刻 T_cut，上料区停止接收 model_A、开始接收 model_B。此后物料流转顺序为：

```
① 上料区残留 model_A（≤10篮）→ 工艺区 → 下料区   [纯 model_A，无混料]
② AGV 送来的 model_B          → 工艺区 → 下料区   [纯 model_B，无混料]
   交界处：①最后1篮 与 ②第1篮 在传送带上短暂共存
         → 下料区出现 1～m 个混料花篮
```

**关键定义——残留消耗时长**：

```
残留消耗时长 = 上料区最大容量 × 每篮片数 / 机台实际产能
             = 10篮 × 120片/篮 / 静态表7[机台ID, model_A].实际产能(片/h)
             = 1200 / 静态表7[机台ID, model_A].实际产能(片/h)
```

物理含义：T_cut 时上料区在最坏情况下积压满 10 篮 model_A，全部通过工艺区处理完所需的时间（保守上界）。

**关键定义——AGV 送料时长**：

```
AGV 送料时长 = T_cut 之后，第一批 model_B 由 AGV 送达上料区的预估时间
             = agv_delivery_minutes（由甲方提供，写入配置参数）
```

### 4.1 混料起始时刻计算

每次切线事件发生时，立即计算混料到达时刻：

```
切线事件 = (机台ID, 切线时刻 T_cut, 前型号 model_A, 后型号 model_B)

残留消耗时长 = 1200 / 静态表7[机台ID, model_A].实际产能(片/h)
AGV 送料时长 = agv_delivery_minutes（配置参数）
工艺时长     = 静态表7[机台ID, model_A].工艺时长(h)

混料起始时刻 T_mix_start = T_cut + 残留消耗时长 + AGV 送料时长 + 工艺时长
```

物理含义：T_cut 后上料区残留 model_A 先走完，AGV 再把 model_B 送到，model_B 经过完整工艺时长后，model_A/model_B 交界批次到达下料区，此时刻为混料起始。

**混料标记对象**：T_mix_start 时刻起，下料区第 **1～m 个花篮**标记为混料（m 为配置参数，建议初始值 = 2）。

**例**：机台 pk03（硼扩），10:00 从 HG210R 切换为 HG182T

```
切线事件 = (pk03, T_cut=10:00, 前型号=HG210R, 后型号=HG182T)

残留消耗时长 = 1200 / 9600(片/h) = 0.125h = 7.5min
AGV 送料时长 = 5min（配置参数）
工艺时长     = 静态表7[pk03, HG210R].工艺时长 = 1h

T_mix_start = 10:00 + 7.5min + 5min + 60min = 11:12.5

含义：
  10:00～11:12.5  下料区纯输出 HG210R（无混料）
  11:12.5         model_A/B 交界批次到达下料区，混料起始
  11:12.5 起第1～2篮  标记为混料批次（含 HG210R + HG182T）
  此后            下料区纯输出 HG182T
```

### 4.2 多次切线叠加

同一机台发生多次切线时，每次切线独立计算其混料起始时刻，产生独立的混料通知记录。

```
切线链 = [(T1, X→Y), (T2, Y→Z), ...]  按时间排序

第 k 次切线 (Tk, 前型号 Pk → 后型号 Qk)：
  残留消耗时长_k = 1200 / 静态表7[机台ID, Pk].实际产能
  工艺时长_k     = 静态表7[机台ID, Pk].工艺时长
  T_mix_start_k  = Tk + 残留消耗时长_k + AGV送料时长 + 工艺时长_k
  混料通知_k：T_mix_start_k 时刻起第 1～m 篮，型号组成 = {Pk, Qk}
```

各次切线的混料通知独立推送至 MES，通过机台 ID 和切线时刻关联展示。

### 4.3 混料片数估算

每个混料批次的片数估算基于 m 篮的实际容量，型号组成按各占一半保守估计：

```
混料批次估算总片数 = m × 120 片

型号组成分配：
  model_A 估算片数 ≈ (m/2) × 120
  model_B 估算片数 ≈ (m/2) × 120
  （实际比例取决于传送带节拍，系统无法精确获取，按各占一半保守估计）
```

**例**：m=2，混料批次（HG210R/HG182T）
```
混料批次估算总片数 = 2 × 120 = 240 片
  { HG210R, 顺序:1, 估算片数:120 }
  { HG182T, 顺序:2, 估算片数:120 }
```

### 4.4 MES 接口推送

我方系统负责计算并推送混料起始时刻，甲方 MES 系统负责完成花篮级别的混料标记。

**我方系统推送数据结构：**

```
混料通知 {
  通知ID,
  来源机台ID,
  切线时刻: T_cut,
  前型号: model_A,
  后型号: model_B,
  混料起始时刻: T_mix_start,
  混料花篮数: m,
  型号组成: [
    { 型号, 顺序, 估算片数 },
    ...
  ]
}
```

**甲方 MES 系统处理逻辑：**

MES 已有数据：花篮 ID + 花篮到达下料区时间。MES 收到混料起始时刻后，匹配时间点前后的花篮，标记 1～m 篮为混料批次。

**推送时机**：切线事件发生时立即推送，MES 可在混料实际到达前完成标记准备。

### 4.5 混料通知生命周期

```
创建并推送：切线事件发生时立即计算 T_mix_start，推送至 MES
关闭：当前时间 >= T_mix_start 时，通知状态置为"已到达"
      （混料交界批次已进入下料区，MES 侧完成标记）
```

| `agv_delivery_minutes` | 切线后 AGV 送料到达预估时长 | 由甲方提供 |

## 七、算法局限与边界说明

| 场景 | 处理方式 |
|---|---|
| 多产线同时触发预警 | 按"耗尽预测时间最短"优先处理，队列化执行 |
| 无候选机台 | 输出人工介入提示，附机台数据及所需产能 |
| 跨尺寸或跨形状代码切线 | 不纳入算法推荐，人工介入处理 |
| 机台数据半小时才刷新 | 净消耗速率基于上一次快照计算，存在最大半小时误差，预警提前量需覆盖此误差 |
| Poly 下料不可缓存 | Poly 下料区库存不纳入 Buffer 净消耗速率计算，仅监控 AGV 车队列长度作为代理指标 |
| agv_delivery_minutes 未提供 | 混料起始时刻计算中 AGV 项置为 0，输出标注"AGV 时长待确认" |

## 八、完整流程示例

### 场景背景

- 车间 S1，Buffer 段 1（制绒→碱抛上），段总容量 156000 片
- 当前在产型号：HG182T（182尺寸，R型）、HG182R（182尺寸，R型）
- 系统调度周期：5 分钟，切线提前量：30 分钟，AGV 送料时长：5 分钟

---

### Step 1：基础层计算（08:00，静态快照）

**当前运行机台产能快照**

| 机台 | 工序 | 当前型号 | 尺寸 | 形状 | 状态 | 有效产能 |
|---|---|---|---|---|---|---|
| zr01 | 制绒 | HG182T | 182 | R | 运行 | 8000 片/h |
| zr02 | 制绒 | HG182T | 182 | R | 运行 | 8000 片/h |
| zr03 | 制绒 | HG182R | 182 | R | 运行 | 8000 片/h |
| zr04 | 制绒 | HG182R | 182 | R | 待机 | 0（不纳入） |
| pk01 | 硼扩 | HG182T | 182 | R | 运行 | 9600 片/h |
| pk02 | 硼扩 | HG182T | 182 | R | 运行 | 9600 片/h |
| pk03 | 硼扩 | HG182R | 182 | R | 运行 | 9600 片/h |

**区间净消耗速率（仅统计运行中机台）**

```
HG182T：
  区间[制绒→硼扩]：硼扩吞入(pk01+pk02)=19200 - 制绒产出(zr01+zr02)=16000 = +3200 片/h ← 消耗

区间库存[制绒→硼扩, HG182T] = 6000 片
耗尽预测时间 = 6000 / 3200 = 112min → 不触发，继续监测
```

---

### Step 2：触发预警（08:30）

```
区间库存[制绒→硼扩, HG182T] 降至 1600 片
耗尽预测时间 = 1600 / 3200 = 30min = cutline_lead_minutes → 触发断料预警 ✓
```

---

### Step 3：候选机台筛选与方案推荐（08:30）

```
筛选条件：工序=制绒、尺寸=182、形状=R、状态=运行、当前不生产 HG182T

候选机台：zr03（HG182R，182尺寸，R型，运行，产能8000片/h）
          zr04：待机 → 排除

借出影响校验（zr03）：
  借出后 HG182R 制绒产能 = 0
  区间耗尽预测时间[制绒→硼扩, HG182R] = 20000 / 9600 = 125min > 30min → 通过 ✓

产能缺口 = 3200 片/h，zr03 切换后可贡献 8000 片/h → 补足
```

**输出切线方案：**

```
切线方案 {
  预警时间: 08:30
  预警类型: 断料预警
  预警区间: 制绒 → 硼扩
  预警型号: HG182T，产能缺口: 3200 片/h
  借用机台: zr03（HG182R，182尺寸，R型，空闲度20%，切换后贡献8000片/h）
  切线开始时间: 08:30（立即执行）
}
```

操作员确认，zr03 切换为生产 HG182T。

---

### Step 4：混料通知推送（08:30，切线发生时立即触发）

```
切线事件 = (zr03, T_cut=08:30, 前型号=HG182R, 后型号=HG182T)

残留消耗时长 = 1200 / 8000 = 0.15h = 9min
AGV 送料时长 = 5min
工艺时长     = 静态表7[zr03, HG182R].工艺时长 = 40min

T_mix_start = 08:30 + 9min + 5min + 40min = 09:24

推送混料通知至 MES：
  来源机台: zr03
  切线时刻: 08:30
  前型号: HG182R，后型号: HG182T
  混料起始时刻: 09:24
  混料花篮数: 2篮（约240片）
  型号组成: { HG182R, 顺序:1, 估算片数:120 }, { HG182T, 顺序:2, 估算片数:120 }
```

---

### Step 5：切回判断（持续监测）

```
08:30 切线后：
  制绒产出 HG182T = zr01+zr02+zr03 = 24000 片/h
  硼扩吞入 HG182T = pk01+pk02 = 19200 片/h
  净消耗速率 = 19200 - 24000 = -4800 片/h（积累）

持续到 08:50（20min = stability_window）：
  条件1：-4800 < 0 ✓
  条件2：持续 20min ✓
  条件3：区间库存 = 1600 + 4800×(20/60) = 3200 片 > 安全水位 2400 片 ✓

→ 触发切回建议：zr03 切回生产 HG182R
```

切回发生，系统同步推送第二条混料通知（08:50 切回事件，T_mix_start = 09:44）。
