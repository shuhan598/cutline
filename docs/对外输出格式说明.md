# 切线算法服务 — 对外输出格式说明

> 面向对接方（后端）说明算法服务的两类对外响应数据结构、字段含义与示例。
> 字段定义来源：`app/schemas/response_schema.py`、`app/schemas/common_schema.py`。

---

## 一、总览

### 1.1 两个对外入口

| 业务 | 入口 | 输入 | 输出对象 |
| --- | --- | --- | --- |
| 切线评估 | `CutlineService().evaluate(snapshot)` | `CutlineSnapshot` | `CutlineEvaluateResponse` |
| 混料追溯 | `MixTraceService().trace(request)` | `MixTraceRequest` | `MixTraceResponse` |

### 1.2 输出形态

输出为标准 JSON 对象（算法结果对象经 `model_dump_json()` 序列化）。下文示例均为 `model_dump_json(indent=2)` 的实际输出（时间值已统一为标称时刻便于阅读，见 1.4）。

### 1.3 通用约定

- **命名**：全部 `snake_case`。
- **列表字段**：无数据时为 `[]`，不会是 `null`。
- **可空字段**：无值时为 `null`。
- **单位**：速率 = 片/小时；数量/库存 = 片；时间间隔 = 分钟；时刻 = ISO 8601 字符串（如 `2026-06-20T10:00:00`）。

### 1.4 时间字段来源

`warning_time`、`suggestion_time`、`tracked_events[].cut_time` 等多数时刻字段取自 `snapshot.current_time`（本次评估的快照时间）。`mix_start_time`、丝网预警的 `warning_time`（= 清台准备时刻）等是算法推算出的时刻，均为 ISO 8601 字符串。

### 2.2 各列表入选规则

| 列表 | 哪些会进入 |
| --- | --- |
| `warnings` | 仅已触发的断料/溢满预警，加上已触发的丝网清台准备预警；未触发的不输出 |
| `plans` | 候选池逐台选取后能补足缺口（断料）或消除积累（溢满）的方案 |
| `manual_interventions` | 有预警但无合规候选、或候选补不齐缺口的情形 |
| `return_suggestions` | 仅已触发的切回建议 |
| `tracked_events` | **全部** `active_cutline_events`（不论本轮是否触发切回），用于后端跨周期续存 |

> 同一条预警可能同时出现在 `warnings`（作为预警）与某个 `plans` / `manual_interventions` 条目的内嵌 `warning` 中。

### 2.3 `WarningResult`（预警）

`warning_type` 三类取值：`stockout`（断料）、`overflow`（溢满）、`silk_screen_order`（丝网清台准备）。

| 字段 | 类型 | 可空 | 单位 | 说明 |
| --- | --- | --- | --- | --- |
| `warning_id` | string | 是 | — | 预警 ID |
| `warning_time` | datetime | 否 | — | 预警触发时间；丝网类为清台准备时刻 |
| `warning_type` | string | 否 | — | `stockout` / `overflow` / `silk_screen_order` |
| `buffer_code` | string | 否 | — | 预警 Buffer 段；丝网类为空串 `""` |
| `upstream_process_code` | string | 否 | — | 区间上游工序；丝网类 = 该工序自身 |
| `downstream_process_code` | string | 否 | — | 区间下游工序；丝网类 = 该工序自身 |
| `product_code` | string | 否 | — | 预警产品型号 |
| `inventory_quantity` | float | 是 | 片 | 当前区间库存；丝网类为 `null` |
| `net_rate` | float | 是 | 片/小时 | 区间净消耗速率（正=减少、负=积累）；丝网类为 `null` |
| `prediction_minutes` | float | 是 | 分钟 | 预测耗尽（断料）/ 溢满（溢满）时间；丝网类为 `null` |
| `cutline_lead_minutes` | float | 是 | 分钟 | 切线提前预警阈值；丝网类为 `null` |
| `capacity_gap` | float | 是 | 片/小时 | 产能缺口或过剩量 |
| `message` | string | 是 | — | 说明；丝网类为 `"silk_screen_clear_preparation"` |

> **内嵌位置**：当 `WarningResult` 作为 `plans[].warning` / `manual_interventions[].warning` 出现时，用于标识预警来源，主要含 `warning_time`、`warning_type`、`buffer_code`、`upstream/downstream_process_code`、`product_code` 等定位字段；完整预警数值请取顶层 `warnings` 列表。

### 2.4 `CutlinePlan`（切线方案）与 `SelectedMachine`

`CutlinePlan` 字段：

| 字段 | 类型 | 可空 | 单位 | 说明 |
| --- | --- | --- | --- | --- |
| `plan_id` | string | 是 | — | 切线方案 ID |
| `warning` | WarningResult | 否 | — | 触发该方案的预警（定位字段，见 2.3 内嵌位置说明） |
| `selected_machines` | SelectedMachine[] | 否 | — | 建议切线的机台列表 |
| `total_contribution_capacity` | float | 否 | 片/小时 | 补充产能合计 |

| 字段 | 类型 | 可空 | 单位 | 说明 |
| --- | --- | --- | --- | --- |
| `intervention_id` | string | 是 | — | 人工介入提示 ID |
| `warning` | WarningResult | 否 | — | 触发的预警（定位字段，见 2.3 内嵌位置说明） |

### 2.7 `CutlineEvent`（`tracked_events` 回吐事件）

用于把被跟踪切线事件的最新状态回吐给后端续存，**下个评估周期请原样回传到 `snapshot.active_cutline_events`**。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `equipment_code` | string | 否 | 发生切线的机台 |
| `cut_time` | datetime | 否 | 切线发生时间 |
| `previous_product_code` | string | 否 | 切线前型号 |
| `next_product_code` | string | 否 | 切线后型号 |
| `negative_start_time` | datetime | 是 | 净速率首次转负时间，**由后端跨周期持久化并回吐**；尚未转负时为 `null` |

| `source_plan_id` | string | 是 | 来源切线方案 ID |

## 三、混料追溯响应 `MixTraceResponse`

### 3.1 顶层结构

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| `success` | bool | 否 | 是否成功；缺机台静态产能/工艺时长时为 `false` |
| `message` | string | 否 | 失败时给出原因，成功时为 `""` |
| `notifications` | MixTraceNotification[] | 否 | 混料通知列表；一次切线事件产出一条，失败时为 `[]` |

### 3.2 `MixTraceNotification`（混料通知）

| 字段 | 类型 | 可空 | 单位 | 说明 |
| --- | --- | --- | --- | --- |
| `notification_id` | string | 是 | — | 混料通知 ID |
| `source_equipment_code` | string | 否 | — | 发生切线的来源机台 |
| `cut_time` | datetime | 否 | — | 切线发生时间 |
| `previous_product_code` | string | 否 | — | 切线前型号 |
| `next_product_code` | string | 否 | — | 切线后型号 |
| `mix_start_time` | datetime | 否 | — | 混料起始时刻 = `cut_time` + 残留消耗 + AGV 送料 + 工艺时长 |
| `mix_basket_count` | int | 否 | 篮 | 混料花篮数（≥1） |
| `estimated_total_quantity` | float | 否 | 片 | 混料批次估算总片数 = `mix_basket_count` × 单篮容量 |
| `product_compositions` | object[] | 否 | — | 型号组成，见下 |
| `status` | string | 否 | — | `pending`（未到混料时刻）/ `arrived`（已到） |
| `message` | string | 是 | — | 混料通知说明 |

`product_compositions[]` 每个元素结构（前后两段各半）：

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `product_code` | string | 型号；`sequence_no=1` 为切线前型号，`=2` 为切线后型号 |
| `sequence_no` | int | 段序号（1、2） |
| `estimated_quantity` | float | 该段估算片数 = `mix_basket_count` ÷ 2 × 单篮容量 |

成功示例（`examples/cutline_mix_trace_input.json`）：

```json
{
  "success": true,
  "message": "",
  "notifications": [
    {
      "notification_id": null,
      "source_equipment_code": "pk03",
      "cut_time": "2026-06-20T10:00:00",
      "previous_product_code": "HG210R",
      "next_product_code": "HG182T",
      "mix_start_time": "2026-06-20T11:12:30",
      "mix_basket_count": 2,
      "estimated_total_quantity": 240.0,
      "product_compositions": [
        { "product_code": "HG210R", "sequence_no": 1, "estimated_quantity": 120.0 },
        { "product_code": "HG182T", "sequence_no": 2, "estimated_quantity": 120.0 }
      ],
      "status": "pending",
```
